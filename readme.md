# usage
change syncdir (where pdfs are saved)

change vaultdir and basedir to the directory of your obsidian vault and where you want the imports to be stored

run sync.py 
# mappings
change mappings with your own course/folders and their relative paths in your vault
key for the mappings should be their path in the synced folder, ie Journal in your sync folder and where you want the notes from that folder to be saved in the vault
